## PHASE 1: DATA COLLECTION (COMPLETE)

### Dataset 1 — APY (Area, Production, Yield)
- Source    : Kaggle (Government of India, district-wise season-wise)
- Coverage  : All India, 1997–2020, 55 crops, 762 districts, 37 states
- Filtered  : Top 16 crops selected for training (see crop list below)
- File      : APY.csv (345k rows raw, 190k rows after crop filter)

### Top 16 Crops Selected for Training:
  Rice, Maize, Moong(Green Gram), Urad, Groundnut, Wheat,
  Rapeseed & Mustard, Sugarcane, Arhar/Tur, Potato, Onion,
  Gram, Jowar, Dry chillies, Bajra, Soyabean

### Dataset 2 — NASA POWER Historical Weather + Soil
- Source    : NASA POWER API (MERRA-2 reanalysis, no auth required)
- Coverage  : All India, 730/762 districts fetched, 1997–2019
- Variables : T2M, T2M_MAX, T2M_MIN, PRECTOTCORR, RH2M, WS2M,
              ALLSKY_SFC_SW_DWN, GWETROOT (root zone soil), GWETTOP (surface soil)
- Fetch     : 1 API call per district for full date range (parallel, 4 workers)
- Duration  : ~38 minutes total fetch time
- Output    : nasa_power_seasonal.csv (48,048 rows, 33 states, 668 districts)
- Note      : ET0 parameter returned fully null — dropped from features

### Dataset 3 — MODIS NDVI Historical (via GEE)
- Source    : MODIS/061/MOD13A3 (monthly, 1km resolution, 2000–2019)
- Coverage  : Batch 1 (5 states: UP, MP, Karnataka, Bihar, Maharashtra)
              Batch 2 (12 states: Odisha, Rajasthan, Gujarat, AP, Tamil Nadu,
              Assam, Chhattisgarh, West Bengal, Haryana, Jharkhand, Punjab, Telangana)
- Fetch     : Optimized — 1 GEE call per month covers ALL districts simultaneously
              using ee.FeatureCollection + reduceRegions (95% fewer API calls vs naive approach)
- Duration  : ~30 min per batch
- Output    : ndvi_historical_all_india.csv (148,473 rows, 17 states, 540 districts)
- Note      : Years 1997–1999 have no NDVI (MODIS starts 2000) — handled via imputation

## PHASE 2: DATA MERGING (COMPLETE)

### Merge Pipeline (merge_and_train.py)
- APY (yield labels) inner-joined with NASA POWER on [State, District, Season, Crop_Year]
- NDVI left-joined on [State, District, Crop, Season, Crop_Year]
- Retention: 186,185 / 190,676 rows (97.6%) after APY+NASA merge
- NDVI coverage: 78.9% of rows (pre-2000 rows + states outside NDVI batches = NaN)
- After yield outlier capping + null drop: 184,436 clean rows
- Output: merged_dataset.csv

### Feature Engineering Applied:
  Raw weather (9 features): temp_mean, temp_max, temp_min, rainfall_mm,
  humidity_pct, wind_speed_ms, solar_radiation_mj, soil_moisture_root,
  soil_moisture_surface, season_days

  Engineered (7 features): temp_range_c, soil_moisture_composite,
  gdd_proxy (Growing Degree Days), heat_stress, aridity_index,
  ndvi_season_mean, ndvi_available (flag: 1 if real NDVI, 0 if imputed)

  Categorical (25 features): crop dummies (16) + season dummies (4) + area_ha
  Total: 41 features

## PHASE 3: MODEL TRAINING (COMPLETE)

### Train/Test Split
- Strategy   : Temporal split (last 3 years = test, NOT random)
  Train: 1997–2017 (164,807 rows)
  Test : 2018–2020 (19,629 rows)

### Models Evaluated:
  Ridge Regression      : MAE=2.977  RMSE=7.027  R²=0.789
  Random Forest         : MAE=1.821  RMSE=5.054  R²=0.891
  Gradient Boosting     : MAE=1.814  RMSE=4.834  R²=0.900  ← WINNER

### Best Model: Gradient Boosting Regressor
  n_estimators=400, learning_rate=0.05, max_depth=6,
  min_samples_leaf=4, subsample=0.8, random_state=42

### Honest Per-Crop R² (on test set):
  Wheat          R²=0.567   MAE=0.618 T/Ha   ← good
  Bajra          R²=0.744   MAE=0.873 T/Ha   ← good
  Sugarcane      R²=0.519   MAE=14.47 T/Ha   ← good (high scale)
  Potato         R²=0.502   MAE=4.448 T/Ha   ← acceptable
  Onion          R²=0.449   MAE=4.537 T/Ha   ← acceptable
  Dry chillies   R²=0.417   MAE=0.914 T/Ha   ← acceptable
  Rice           R²=0.274   MAE=0.636 T/Ha   ← weak (monsoon variance)
  Maize          R²=0.323   MAE=0.933 T/Ha   ← weak
  Groundnut      R²=0.131   MAE=0.520 T/Ha   ← poor
  Arhar/Tur      R²=-0.079  MAE=0.330 T/Ha   ← poor (needs soil type feature)
  Gram           R²=-0.066  MAE=0.327 T/Ha   ← poor
  Soyabean       R²=-0.011  MAE=0.334 T/Ha   ← poor

  Note: Overall R²=0.90 is inflated by Sugarcane scale dominance.
  Per-crop R² is the honest benchmark. Pulse crops (Arhar, Gram, Urad)
  need additional features (soil type, irrigation access) — Semester 7 target.

## PHASE 4: FLASK + FRONTEND INTEGRATION (COMPLETE)

### app.py (fully rewritten)
- Loads yield_model.pkl, scaler.pkl, model_metadata.json at startup
- CROP_BASELINES heuristic fully removed
- New /api/fetch_ndvi route:
    1. Season status check (active / completed / not_started)
    2. Fetches live NDVI from GEE Sentinel-2 (last 90 days)
    3. Fetches season weather from NASA POWER (season start → today)
    4. Builds 41-feature vector matching training schema exactly
    5. Runs Gradient Boosting model → yield prediction
    6. Returns: prediction, ndvi, weather summary, season window, model name
- Season windows defined per crop:
    Sugarcane  → Whole Year (Jan–Dec)
    Wheat/Gram/Mustard/Potato/Onion → Rabi (Oct–Mar)
    Rice/Maize/Bajra/Jowar/Groundnut/Arhar/Moong/Urad/Soyabean/Chillies → Kharif (Jun–Nov)
- "not_started" response returned for Kharif crops (season begins June)

## KNOWN LIMITATIONS (TO STATE IN PRESENTATION)

1. NDVI not in training data directly — historical NDVI fetched at district
   centroid level. Per-farm NDVI used only at inference time as adjustment signal.
2. 29 districts missing from NASA POWER fetch due to name mismatches in APY
   (BADGAM, FIROZEPUR, etc.) — 668/762 = 87.7% coverage, acceptable.
3. Pulse crop R² is negative — these crops need soil type and irrigation
   features not available in current dataset. Planned for Semester 7.
4. NASA POWER has 3-5 day lag — inference weather is always slightly behind.
   Acceptable for seasonal prediction use case.
5. archive.open-meteo.com blocked on local network — NASA POWER used instead.
6. ET0 (evapotranspiration) returned null from NASA POWER — dropped from features.
